Projeto do Observatório Oceanográfico

Use este formulário para propor a inclusão ou atualização de um projeto no Observatório Oceanográfico. Antes de enviar, converse com André Belem (andrebelem@id.uff.br), curador do Observatório.

O conteúdo pode ser escrito em Markdown simples. Se precisar de ajuda, consulte este guia: https://docs.pipz.com/central-de-ajuda/learning-center/guia-basico-de-markdown#open

Por favor, revise os seguintes campos:

    Idioma desta submissão

    Escreva o projeto em apenas um idioma. A segunda versão (PT ou EN) é produzida depois pela equipe de curadoria.

    Dados do projeto

    Texto curto, usado em listagens e cards do projeto.

    Áreas / temas

    Opcional. Pressione Enter ou vírgula para adicionar. Clique no × para remover.

    Instituições e apoio

    Opcional. Uma instituição por linha. Ex.: Universidade Federal Fluminense.

    Opcional. Um item por linha. Ex.: CNPq, FAPERJ, Schmidt Ocean Institute.

    Imagem principal

    Opcional. JPG, PNG ou WEBP, até 8 MB. A imagem é processada inteiramente no seu navegador: redimensionada quando necessário e convertida para JPEG, sem recorte — todo o conteúdo da imagem é preservado. Durante a curadoria, derivados apropriados para card e banner são gerados a partir desta mesma imagem.

    Conteúdo do projeto

    Markdown simples é aceito: ## para subtítulos, - para listas, **negrito**, *itálico* e [texto](https://link) para links. HTML digitado aqui não é interpretado — aparece como texto puro.

    Prévia

    Dados gerados

    Este é o payload desta submissão, já enviado ao servidor (veja o status acima). Campos de curadoria (slug, filename, layout, collection, permalink, alt_lang, ordem, caminhos de imagem, header.teaser, header.overlay_image, status interno, grupos internos de ordenação) não fazem parte deste formulário — são definidos depois pela equipe de curadoria. Os botões abaixo baixam o JSON e a imagem processada apenas para conferência local.
